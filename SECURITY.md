# Security Policy

Please report suspected vulnerabilities privately via **GitHub Security Advisories**
("Report a vulnerability" on this repository). Vulnerabilities in the SDK itself belong to
[aiquilibria/atp-python](https://github.com/aiquilibria/atp-python/security); protocol-level
reports belong to
[aiquilibria/agenttrustprotocol](https://github.com/aiquilibria/agenttrustprotocol/security).
